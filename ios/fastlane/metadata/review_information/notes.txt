Spool Master v1.4.11 - Review Notes

This is a maintenance release: no new features, permissions or entitlements.

1. NFC - COLOR NAMES: spools from Anycubic NFC tags now get more accurate color names (for example beige, brown, purple, pink, gold, silver, cyan). Transparent PETG spools are recognized and shown with a hatched color swatch.

2. NFC - SCAN MESSAGE: if the NFC tag moves away from the phone during a scan, the app now shows "hold the tag still and try again" instead of a generic error.

3. ACCOUNT DELETION: Profile > Delete my account. The account and all its data are deleted immediately on our server (Guideline 5.1.1(v)). The confirmation dialog and the final message now state this; they previously mentioned a 30-day delay.

4. Minor fixes.

STATE OF THE APP:
- NO new permissions or entitlements in this version.
- NFC access is read-only when scanning; nothing is written to the tag when scanning.
- In-app subscriptions are unchanged from version 1.3.2.

TESTING NOTES:
- Most features can be tested without an NFC tag: Stock tab > Add spool > Add manually, then use search, edit (Location / Notes), the calculator icon, the "more" menu (export / import) and the Statistics tab.
- NFC scanning requires a physical NFC tag from a supported 3D printer filament spool.
- In-app subscriptions: spool_master_monthly and spool_master_yearly (auto-renewable), unchanged from 1.3.2. Tap Profile > Premium subscription. If not signed in, the app asks to sign in (Sign in with Apple) before purchase.
